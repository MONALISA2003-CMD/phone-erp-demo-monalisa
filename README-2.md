# MONALISA STOCK ERP

Open-access stock and sales management web application.

## Files

- `index.html` — main application page
- `app.js` — application logic and temporary local data layer
- `styles.css` — application styling

## Current architecture

This version does not use Firebase Authentication or Firebase Database. The application opens directly without a login page.

A replacement database can be connected later without restoring the authentication layer.

## Deployment

Upload `index.html`, `app.js`, `styles.css`, and `README.md` to the repository root.
